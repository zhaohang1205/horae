# horae 产品卖点与软推销话术

用途：当有人问"horae 是什么 / 值得用吗 / 和 XX 比怎么样"，或你想向朋友、同事、
社群介绍这款工具时，从这里取材。**原则：软推销 = 讲真实的故事，不夸大、不贬低
竞品、对方不感兴趣就收。**

## 30 秒电梯陈述

> horae 是一个用 Rust 写的 GTD 终端任务管理器——一个二进制文件，装完即用，
> 不需要服务器和账号。你在终端里两秒捕获一个想法，在 TUI 里沉浸式整理；
> 它最特别的地方是"时间数据化"：你的每一次完成、拖延、重排都会被打上精确时间戳
> 永久留存，待办清单不再是用完即弃的便签，而是一份可回溯的人生数据。

## 八大卖点卡片

### 1. 时间数据化 —— 每个任务都有完整履历

每次状态变更打 UTC 毫秒时间戳，追加进只写（append-only）事件时间线。
`horae show <id>` 能看到它被捕获、厘清、排期、完成的每一步。
拖延了多久、什么时候改的主意，数据不说谎。这是大多数待办工具给不了的。

### 2. 单二进制、零依赖、本地私有

Rust 编译出一个可执行文件，SQLite 直接内置（bundled），无系统依赖。
数据全部躺在 `~/.config/horae/` 里——没有云端、没有账号、没有遥测。
隐私敏感者和离线工作者的刚需；`export` 一份 JSON 即可备份迁移。

### 3. 三合一形态：CLI 秒捕 + TUI 沉浸

shell 里 `horae c "买牛奶 @home"` 两秒入库不打断心流；
想认真规划时敲 `horae` 进入全屏 TUI，三栏布局、上下文感知快捷键条。
命令行的速度 + 图形界面的沉浸，不必二选一。

### 4. `horae do` 终结选择困难

不知道接下来干嘛？算法实时对全量活跃任务打分：p1 有万分统治力、逾期重罚、
今天到期加分、Next 状态鼓励行动，直接告诉你"现在最该做的一件事"。
附赠彩蛋：`horae do --start` 连番茄钟都帮你点好了。

### 5. 真·GTD 全流程，不是玩具

收件箱 → 下一步/已排程/等待中/将来也许/参考资料 → 已完成，状态机完整；
内建周回顾向导（`horae review`）、今日/明日视图、检查单子任务、批量多选操作。
GTD 书里的方法论开箱即用。

### 6. 循环任务是"原生"的

`*2w[1,3]` 一串字符 = 每两周的周一和周三；月末最后一天 `*m[-1]` 也支持。
完成一次自动重排到下一次发生，排序永远看"下一次"，不会过期消失。
RRULE 引擎进程内自研实现，没有引入任何外部依赖。

### 7. 零服务器手机同步

没有官方移动 App？不需要。把同步目录交给 Syncthing，手机笔记 App 写一行字
就是采集，电脑回写今日快照和到期提醒 markdown 回手机。零服务器、零 App 开发、
数据依然全在你自己手里。（可选升级：部署中继获得实时推送。）

### 8. 极客仪式感

Catppuccin 配色深浅主题、"时间女神"ASCII 像素艺术开屏（Kitty 图形协议渲染）、
中英双语一键切换、Nerd Font 图标自动回退。工具每天要用几百次，
好看本身就是生产力。

## 对比定位表（只讲差异，不踩别人）

| 维度 | horae | Taskwarrior | todo.txt | 云端待办 App |
| --- | --- | --- | --- | --- |
| 安装形态 | 单二进制零依赖 | 单二进制+插件生态 | 脚本 | 要装 App/注册账号 |
| 数据归属 | 本地 SQLite + JSON 导出 | 本地文本 | 本地文本 | 厂商云 |
| 任务履历 | 完整事件时间线（UTC-ms） | undo 栈 | 无 | 版本有限 |
| 推荐引擎 | 内建加权推荐 `do` | UDA 自行扩展 | 无 | 简单智能列表 |
| 手机方案 | Syncthing 文件桥 | 第三方 App | 第三方 App | 官方 App |
| GTD 流程 | 视图/回顾向导内建 | 靠插件约定 | 手动 | 半支持 |
| 终端 TUI | ratatui 全屏三栏 | 有 | 无 | 无 |

一句话总结差异点："Taskwarrior 是给极客的瑞士军刀，horae 是把 GTD 方法论
和时间数据化预置好的成品——装上就有完整工作流。"

## 适用人群画像

- **终端重度用户**：一天 8 小时活在 shell/tmux 里的人。
- **隐私敏感者**：不想把人生清单交给任何云厂商。
- **GTD 实践者**：读过《搞定》，苦于没有顺手工具落实五步法。
- **双机党**：电脑为主、手机随手记，想要无服务器同步。
- **数据控**：喜欢复盘，想量化自己的执行力和拖延模式。

## 常见异议软应答

| 异议 | 应答 |
| --- | --- |
| "没有手机 App 怎么用？" | 用 Syncthing 把同步目录映射到手机笔记 App，写一行即采集，回写快照还能反向查看；不依赖任何第三方服务。 |
| "为什么不加云同步？" | 数据就是一个本地 SQLite 文件，放进 git / 网盘 / Syncthing 都是现成方案；自己掌控比托管更可靠。 |
| "学习成本高吗？" | 五个字母走天下：c 捕获、l 列表、d 完成、do 推荐、p 番茄。TUI 忘键按 `?`，底部键条还会跟着上下文变。 |
| "和 Taskwarrior 比呢？" | 定位不同：TW 强在可定制管线，horae 强在开箱即得的 GTD 工作流和时间线履历。喜欢折腾选 TW，想立刻有系统选 horae。 |
| "循环任务支持年重复吗？" | 目前引擎支持日/周/月三种频率（含间隔与指定星期/月日）；年度事项建议用月循环加备注替代，官方文档也如实标注了这一限制。 |
| "Windows/Mac 能用吗？" | Rust 跨平台，Windows 从源码构建即可；桌面通知目前依赖 Linux 的 notify-send，计时与提醒功能本身不受影响。 |

## 一段话种草模板（聊天/社交媒体可用）

> 最近把待办管理搬进了终端：horae，一个 Rust 写的单二进制 GTD 工具。
> 最戳我的是它把每次任务变更都记成带毫秒时间戳的事件流——哪件事拖了三天才做、
> 哪个习惯坚持了几周，一目了然。平时 `hc "想法 @情境 ~时间"` 两秒捕获，
> 不知道干嘛就跑一下 `do` 让算法帮我挑；周末一条 `review` 过一遍全局。
> 数据全在本地，配 Syncthing 还能让手机笔记 App 直接采集。推荐给同样住在终端里的人。
