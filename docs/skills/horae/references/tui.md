# horae TUI 完整参考

启动：直接运行 `horae`（无子命令即 TUI）。启动即进入**快速录入模式**（F7 模块开关可关），
光标已在输入框，想到什么打什么。开屏页在支持 Kitty 图形协议的终端（Kitty/Ghostty/WezTerm）
渲染"时间女神"像素艺术，其它终端自动回退 ASCII 版。

界面三栏：左侧引导栏（视图列表 + 上下文键提示）/ 中间任务列表 / 右侧详情面板。
中英双语（`F6` 切换）、Catppuccin 深/浅主题（`F5` 切换）、图标自动回退
（`HORAE_ICONS=nerd|ascii` 可强制）。

## 视图地图

| 数字键 | 视图 | 说明 |
| --- | --- | --- |
| `1` | 收件箱 Inbox | 未厘清的原始输入 |
| `2` | 下一步 Next | 已明确可执行的行动 |
| `3` | 等待中 Waiting | 等他人反馈，逾期会重新浮出 |
| `4` | 已排程 Scheduled | 有计划开始时间（含循环） |
| `5` | 将来也许 Someday | 暂不行动 |
| `6` | 参考资料 Reference | 非行动条目（开启金句后不含 @quote） |
| `7` | 已完成 Done | |
| `8` | 归档 Archived | 软删除区：显示归档原因与时间；`u` 恢复、`D`+y 永久删除 |
| `9` | 标签库 Tags | `c` 新建标签、`D` 删标签 |
| `0` | 金句 Quotes | F7 开启金句功能后可用 |

辅助视图：`⇧J` 今日 / `⇧K` 明日、`r` 周回顾、`W` 工作流（capture→clarify 决策树引导页）、
`M` 设置页（Profile 管理：n 新建 / r 重命名 / d 删除 / s 设默认）。

**今日 / 明日视图的口径**（两者各自独立判定）：

- 今日 = 落在今日窗口内的任务（含循环任务今日的发生点）**加上** 逾期任务；
  循环任务今天没有发生点时，展示最近一次已错过的发生点并标为逾期。
- 明日 = **仅**落在明日窗口内的任务（含循环任务明日的发生点）；
  逾期与今日未完成的任务不结转，第二天也不会在明日视图里重复出现。
- 两个视图都只收**下一步 / 已排程**状态：等待中、将来也许、参考资料与收件箱里
  带日期的任务留在各自的状态视图（逾期仍由每日摘要与周回顾覆盖）。

## 导航与选择

| 键 | 作用 |
| --- | --- |
| `h` / `l` 或方向键 | 切换面板 / 移动 |
| `j` / `k` | 上下移动 |
| `g` / `G` | 跳到首行 / 末行 |
| `v` | 进入/退出可视多选模式（`j/k` 连续扩选） |
| `Space` | 切换勾选当前行（非连续多选） |
| `Ctrl+a` / `Ctrl+u` | 全选 / 反选 |

## 输入与捕获

| 键 | 作用 |
| --- | --- |
| `a` | 快速捕获（任何视图），一句话 quick-add：`标题 @标签 ~时间 *周期 !优先级` |
| `Enter` / `e` | 编辑选中任务全量字段（同一句话语法，输入 `@/~/*/!` 即时弹出智能补全） |
| `/` | 全局搜索（Enter 执行，Esc 清除） |
| `f` | 情境过滤 |
| `Esc` | 取消当前输入/弹层 |
| `Tab`（输入态） | 采纳补全并填入 / 切换候选 |
| `Ctrl+P` | 语法速查弹层 |

自动补全支持双模式（`F7` 切换）：
- **语法参考模式（Cheat-Sheet / Reference，默认）**：以启发表达多样性与常用范式为核心目的，三列卡片展示 Token、语义说明与语法范式（如多样别名 `!1/!h/!高`、循环范式 `*Nw[1..7]`、天词时刻复合等）；
- **极速补全模式（Speed）**：紧凑单列与 Ghost Text 辅助盲打流。
- **多语言适配**：英文模式候选 100% 纯 ASCII（`mon`~`sun`, `today`, `+1d`），中文模式首屏覆盖自然天词、相对偏移、星期与整点时刻等丰富范式。

## 任务操作

| 键 | 作用 |
| --- | --- |
| `x` | 完成（循环任务=重排到下一次） |
| `w` | 转等待中 |
| `s` | 转将来也许 |
| `n` | 编辑长备注（调用 `$EDITOR`） |
| `T` | 批量打标签（配合多选） |
| `A` | 归档（`y` 确认 / `n` 取消） |
| `u` | 恢复归档（支持批量） |
| `D` | 归档视图内 = 永久删除（确认后不可恢复）；标签库内 = 删标签 |

### 检查单

| 键 | 作用 |
| --- | --- |
| `C` | 新增检查项 |
| `=` | 勾选下一项（不自动重置，适合流程化操作） |
| `Tab` | 进入逐项管理模式：`j/k` 移动、`Space` 勾选/取消、`d` 删除项、`J/K` 排序、`e` 改名；`Tab/Esc` 退出 |

列表行显示 `n/total` 进度徽标。

### 番茄钟

| 键 | 作用 |
| --- | --- |
| `P` | 对选中任务开始专注 / 续杯 |
| `S` | 停止 |
| `[` | 配置时长，格式 `工作;短休;长休[;长休周期]`，如 `25;5;15;4` |

### 金句（可选功能，F7 开启）

- 任意视图对选中任务按 `"` → 加入金句（工作态任务自动转参考资料）
- 金句视图内 `a` 直接录入新句子（自动 @quote）；`"` = 移出金句
- 捕获时带 `@quote`（如 `a灵感 @quote`）→ 自动创建为金句并跳转金句视图

## 功能键与全局

| 键 | 作用 |
| --- | --- |
| `F1` / `?` | 快捷键帮助面板（分组 + 按热度排序 + 当前是否可用） |
| `F2` | 开关底部快捷键条 |
| `F5` | 切换主题 |
| `F6` | 切换中英文 |
| `F7` | 模块与补全显示设置弹层（开屏页、金句、图标风格、启动快速录入、补全风格等 11 项开关，持久化） |
| `M` | 设置页（Profile 数据集管理） |
| `r` | 开始周回顾向导（进行中按 `R` 下一步） |
| `q` | 退出 |

## 教学建议（给讲解者）

1. 先演示"想到即捕获"：启动 TUI 直接输入 `给妈妈订生日蛋糕 @calls ~周六 10:00`，
   回车入库——这一步就能讲清 quick-add 价值。
2. 再演示收件箱厘清：选中一条按 `Enter` 补成 Next，或 `x/w/s` 一键分流——GTD 的
   "clarify" 在两个键内完成。
3. 循环任务演示 `*2w[1,3]` + `x` 完成后自动重排。
4. 最后 `P` 起一个番茄钟展示专注环与通知。
5. 提醒新手：底部快捷键条是上下文感知的，忘了键位就按 `?`。
