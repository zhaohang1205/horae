# horae 语法与快速录入全景指南 (Syntax Reference)

在一句话里混排四种前缀 token，空格分词、逐词识别、顺序任意：

```text
标题 @标签 ~时间 *循环简写 !优先级
```

示例：

```sh
horae capture "给妈妈订蛋糕 @calls ~周六 10:00 !1"
horae capture "站会 @work *weekday ~09:30 !high"
horae capture "灵感：少即是多 @quote"                # 配合金句功能
horae capture "对账 @computer *m[-1] ~21:00 !med"   # 每月末 21:00
```

---

## 1. 词法规则与前缀 Token

- **空格分词**：按空白分词，整词匹配前缀；单个 `@`、`~` 等不构成 token（长度 $>1$ 才生效），会被当普通标题文字。
- **位置任意**：四种 token 在标题中的位置任意，解析后从标题中剔除，干净提取核心标题。
- **大小写无关**：所有前缀标记及其别名（包括标签/时间/循环/优先级）均支持大小写不敏感匹配。
- **全角符号兼容**：支持中文全角符号 `＠`、`～`、`〜`、`＊`、`×`、`！` 自动归一化解析。

---

## 2. 优先级语法 (`!priority`)

支持多种别名、数字级别与中文输入：

| 级别 | 权重加成 | 支持的别名写法 |
| :--- | :--- | :--- |
| **高优先级 (High)** | `+10000` | `!high` · `!h` · `!1` · `!p1` · `!高` |
| **中优先级 (Medium)** | `+5000` | `!medium` · `!med` · `!m` · `!2` · `!p2` · `!中` |
| **低优先级 (Low)** | `+1000` | `!low` · `!l` · `!3` · `!p3` · `!低` |

> 💡 **提示**：未识别的 `!xxx`（如 `!important`）会被安全保留在标题中，绝不丢失信息。CLI 中亦可使用 `--high` / `--medium` / `--low` / `--clear-priority`。

---

## 3. 标签与情境 (`@tag`)

- **自动建档**：`@自定义标签` 首次使用即自动在标签库建档。
- **热度加权排序**：TUI 补全时根据历史关联任务频次降序排序，高频标签优先推荐。
- **预设推荐**：`@work` (工作)、`@home` (生活)、`@errands` (外出办事)、`@quick` (5分钟小事)、`@focus` (深度专注)、`@quote` (灵感金句)。

## 4. 时间语法 (`~time` 与 CLI TIME 参数)

| 写法分类 | 示例 | 含义说明 |
| :--- | :--- | :--- |
| **相对偏移** | `now` · `+15m` · `+30m` · `+1h` · `+2h` · `+4h` · `+1d` · `+2d` · `+3d` · `+1w` | 相对当前时刻推移 |
| **相对偏移 + 时刻** | `+3d 15:30` · `+1w 09:00` | 相对天数/周数 + 指定时刻 |
| **自然天词** | `today` · `tomorrow` · `今天` · `明天` · `后天` `[HH:MM]` | 支持接时刻（如 `~today 18:00`）；中文拼音 `~td`/`~tm` 可直接补全 |
| **星期词汇** | `周一`~`周日` · `下周五` · `mon`~`sun` · `next fri` `[HH:MM]` | 自动取未来最近对应星期；支持拼音首字母匹配（如 `~zy` / `~mon` $\to$ `~周一`） |
| **常用整点** | `09:00` · `18:00` · `HH:MM` | 当日指定时刻（已过则自动顺延至明日） |
| **灵活/绝对日期** | `8/20 15:30` · `2026.8.20` · `YYYY-MM-DD [HH:MM]` | 斜杠/点分/标准 ISO 日期与时刻 |

### 核心语义区别：
- **`~time` 设排程起点**（`scheduled_start_at`）：任务状态进入"已排程"（Scheduled）；只设起点不设终点。
- **`--due` 设软截止**（`due_at`）：任务软性截止时间。两者可同时设置：
  `horae schedule <id> --start 明天 09:00 --end 明天 18:00`

## 5. 循环与周期任务 (`*rrule`)

支持单字母简写、括号周期范式、数字动态推导与 RFC 5545 标准。

### 5.1 快捷简写一览

| 简写范式 | 展开含义 | 示例与说明 |
| :--- | :--- | :--- |
| `*d` / `*w` / `*m` / `*y` | 基础周期 | 每天 / 每周 / 每月 / 每年 |
| `*weekday` / `*weekend` | 工作日 / 周末 | 周一至周五 / 周六周日 |
| `*2w[1,3]` / `*1w[mo,we]` | 指定周几 | 每 2 周周一与周三（数字 1-7=周一至日，0=周日；或字母代码） |
| `*m[1,15]` | 月度固定日 | 每月 1 号与 15 号 |
| `*m[1,-1]` / `*m[-1]` | 月初与月末倒数 | 每月 1 号与月末 / 月末最后一天（负数表示月末倒数） |
| `*m[1,2,-2,-1]` | 月首月末各两天 | 每月 1、2 号及倒数第一、二天 |
| `*y[jan,jul]` | 年度指定月份 | 每年 1 月与 7 月（月份名或 1-12） |
| `*2y[6]` | 间隔年 + 月份 | 每两年 6 月 |
| `*Nd` / `*Nw` / `*Nm` / `*Ny` | 动态数字推导 | 输入 `*2` / `*3` 实时动态推导 `*2d` / `*2w` / `*2m` / `*2y` |

### 5.2 RFC 5545 标准格式
```text
;FREQ=DAILY|WEEKLY|MONTHLY|YEARLY;INTERVAL=2;BYDAY=MO,WE;BYMONTHDAY=1,-1;COUNT=10|UNTIL=YYYY-MM-DD
```

## 6. 自动补全与盲打流操作指南

| 交互场景 | 快捷键 / 操作 | 功能说明 |
| :--- | :--- | :--- |
| **触发补全** | 键入 `@`、`~`、`*`、`!` | 实时在输入框下方（或自适应向上翻转）弹出最大 9 行候选列表 |
| **快捷直选** | `Alt+1` ~ `Alt+9` | 极速盲打直选第 1~9 项候选项并立即采纳上屏 |
| **上下导航** | `↓` / `↑` · `Ctrl+N` / `Ctrl+P` · `Ctrl+J` / `Ctrl+K` · `Alt+N` / `Alt+P` | 候选列表中循环滚动切换高亮项 |
| **采纳补全** | `Tab` · `Ctrl+Y` | 采纳当前高亮候选项并自动追加空格 |
| **取消补全** | `Esc` · `Ctrl+E` · `Ctrl+G` | 关闭补全浮层，保留已键入字符 |
| **补全风格切换** | `F7` 弹出层内选择 | 切换「语法参考模式」(提供范式解读与提示) 与「极速补全模式」(极速单列) |
| **智能槽位引导** | 录入标题后按空格 | 未填写维度在行末呈现淡色 `[@标签] [~时间] [*周期] [!优先级]` 占位提示 |

## 7. 典型实战组合速查

| 实际管理需求 | 快速录入一句话 | 解析结果与去向 |
| :--- | :--- | :--- |
| 今天下班前要交 | `写周报 @work ~today 18:00 !high` | 标签: `@work`, 状态: 已排程今日 18:00, 优先级: 高 |
| 每两周周一站会 | `站会 @work *2w[1] ~周一 09:30 !1` | 循环: 每两周周一, 起点: 下周一 09:30, 高优先级 |
| 每月末对账报税 | `月度对账 @finance *m[-1] ~20:00` | 循环: 每月最后一天, 起点: 当月最后一天 20:00 |
| 工作日晨间阅读 | `晨间阅读 30m @focus *weekday ~07:30` | 循环: 周一至周五, 起点: 工作日 07:30, 标签: `@focus` |
| 每年 1 月与 7 月缴保 | `缴纳社保 @errands *y[jan,jul] ~09:00` | 循环: 每年 1 月与 7 月, 起点: 对应月份 09:00 |
| 临时抓取灵感金句 | `少即是多 @quote` | 自动归档至灵感金句库（Reference） |
| 仅设置高优待厘清 | `联系牙医 @calls !high` | 留在收件箱（Inbox），待后续规划厘清 |
