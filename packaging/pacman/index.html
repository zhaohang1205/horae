Horae 任务管理器

极速、现代的 Rust GTD 终端任务管理系统（TUI + CLI）原生软件包源

⚡ 方式一：一键配置并安装（推荐）
零配置

在终端中运行以下命令，自动添加软件源并同步数据库：

curl -sSL https://zhaohang1205.github.io/horae/install-repo.sh | sudo bash
sudo pacman -S horae
🛠️ 方式二：手动添加配置

编辑 /etc/pacman.conf，在文件末尾追加以下配置：

[horae]
SigLevel = Optional TrustAll
Server = https://zhaohang1205.github.io/horae/arch/$arch

然后更新数据库并直接安装：

sudo pacman -Sy horae
